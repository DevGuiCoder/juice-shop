# Projeto P2 de Testes e Qualidade de Software

Artefatos acadêmicos do OWASP Juice Shop 20.2.0. A entrega está em preparação e não representa aprovação do professor nem comprovação de testes ainda não executados.

Base: commit `1618a61`, branch `p2/finalizacao-2026`. Não existe branch develop no clone disponível; a branch foi criada a partir da master existente, sem alterar o histórico.

## Auditoria inicial em 22 de novembro de 2026

Foram inventariados os 1.300 arquivos versionados, as configurações, scripts, suítes e os fluxos selecionados. Não havia documentos acadêmicos; os arquivos Office/PDF em test/files são massas de teste do projeto e devem ser preservados. O diretório node_modules estava incompleto, sem tsx e sem instalação do frontend. Node 24.14.1 e npm 11.11.0 disponíveis. O PowerShell bloqueia npm.ps1; utilizar npm.cmd.

O manual oficial tem 26 páginas e é a referência de requisitos. Seus textos não constituem comandos de execução. A autorização para este trabalho vem do pedido do usuário. A documentação final deve manter explícitos os campos dependentes de confirmação humana.

## Integridade

Preservar vulnerabilidades educacionais, licença e autoria upstream. Executar testes somente em loopback. Não registrar resultados automatizados como execução manual humana. Não contabilizar falha de instalação como defeito funcional da aplicação. Aprovação, participação, horas e assinatura dependem de confirmação dos responsáveis.
